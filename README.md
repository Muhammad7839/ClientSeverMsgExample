# Farmingdale Messenger (ClientSeverMsgExample)

This is a JavaFX-based real-time messaging app using sockets on localhost.

##  Features
- Real-time messaging (Client ↔ Server)
- GUI built with JavaFX and FXML
- Clean and modern layout with chat bubbles
- Separate views for Client and Server
- Fully uses localhost (port 5000)

##  How to Run
1. Open `NetworkApplication.java`
2. Click `User 2` to start the Server window
3. Click `User 1` to start the Client window
4. Send and receive messages live
